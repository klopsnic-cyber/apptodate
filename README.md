# Update-Radar

Prüft die Programme auf deinem Mac auf Updates – auch von Drittanbietern –, zeigt, welche davon wichtig sind, und installiert sie auf Knopfdruck.

- **Apps** aus `/Applications`: Abgleich mit dem Homebrew-Katalog (rund 7.800 Programme), Sparkle-Update-Feeds und dem App Store
- **Kommandozeilen-Pakete** aus Homebrew und **macOS-Updates**
- **Einstufung:** wichtig (Browser, Fernwartung, VPN, Passwortmanager, Office, Kommunikation, macOS), empfohlen (neue Hauptversion), optional
- **Aktualisieren:** über Homebrew direkt vom Hersteller; App-Store-, Sparkle- und macOS-Updates werden an der richtigen Stelle geöffnet

Voraussetzung für automatische Updates: [Homebrew](https://brew.sh). Ohne Homebrew zeigt die App die Updates nur an.

Beim ersten Start (nicht notarisiert): Rechtsklick › Öffnen bzw. Systemeinstellungen › Datenschutz & Sicherheit › Dennoch öffnen.
